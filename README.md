# Patrik Rybka – Osobní web & Portfolio

Osobní portfolio a blog postavené na [Astro](https://astro.build) a [Tailwind CSS](https://tailwindcss.com).

- **Doména:** [patrikrybka.me](https://patrikrybka.me)
- **Hosting:** GitHub Pages (automatický deploy přes GitHub Actions)

## 🛠️ Vývoj lokálně

```bash
# Instalace závislostí
npm install

# Spuštění vývojového serveru (localhost:4321)
npm run dev

# Sestavení projektu (build do složky dist/)
npm run build
```
